# Voiceover review checklist

## Before generation

- Use only text you intend to send to the synthesis provider.
- Read abbreviations and names aloud and rewrite ambiguous wording when needed.
- Separate ideas with punctuation so the script remains understandable.
- Keep the script within the application's displayed character limit.

## After generation

- Listen for omitted words, pronunciation problems, and awkward pauses.
- Check the beginning and end against the original script.
- Verify that the file extension matches the actual audio format.
- Import the file into your video editor and check timing against the video.
- Keep generated narration distinguishable from impersonation or official platform voices.

This checklist is practical editorial guidance, not a measured quality benchmark or a claim that every generated voiceover passes these checks.
